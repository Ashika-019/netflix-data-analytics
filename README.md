# Netflix EDA — Exploratory Data Analysis

## Overview
Exploratory data analysis on Netflix Movies and TV Shows dataset
to identify content trends, genre popularity, country-wise
production, and yearly release patterns.

## Dataset
- Source: [Kaggle — Netflix Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- Rows: ~8800 titles
- Columns: 12 (title, type, director, cast, country, rating, etc.)

## Tools & Libraries
Python | Pandas | NumPy | Matplotlib | Seaborn | Jupyter Notebook

## Key Findings
- Netflix has ~70% Movies and ~30% TV Shows
- USA, India, and UK are top content producers
- Content grew rapidly from 2015 to 2019
- TV-MA is the most common rating
